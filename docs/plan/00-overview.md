## Ключевые решения

### Почему Symfony?
- Хорошо подходит для деплоя на любой VPS
- Doctrine ORM с миграциями — удобно для долгосрочного проекта
- Symfony Messenger — встроенные очереди без лишних зависимостей
- Twig — простой шаблонизатор для веб-дашборда

### Почему Telegram как основной интерфейс?
- Не нужно устанавливать отдельное приложение
- Удобно добавлять расходы с телефона "на ходу"
- Webhook-подход надёжнее long-polling для продакшна

### Почему PostgreSQL?
- Поддержка JSON, ENUM-типов
- Хорошая производительность для аналитических запросов
- Поддержка UUID из коробки

### Хранение состояния диалогов в Redis
- Диалоги многошаговые (выбор суммы → категории → счёта)
- Redis с TTL 30 минут — лёгкое и быстрое решение
- При рестарте сервера незавершённые диалоги теряются (приемлемо)

### Импорт выписок в фоне
- Обработка через Symfony Messenger + отдельный worker-контейнер
- Пользователь не ждёт — получает уведомление по завершении
- Дедупликация по SHA256-хэшу предотвращает двойной импорт

### Графики для Telegram через Quickchart.io
- Chart.js работает только в браузере
- Quickchart.io — бесплатный API для генерации PNG-графиков
- Можно поднять собственный экземпляр для privacy

## Дальнейшие улучшения (после MVP)

- **Мобильный PWA** — Progressive Web App поверх существующего веб-интерфейса
- **Мультивалютность** — курсы из ЕЦБ или fixer.io, конвертация в основную валюту
- **Планирование** — будущие платежи, ипотека, подписки (recurring transactions)
- **OCR чеков** — распознавание фото чека через Tesseract или API
- **Экспорт** — CSV/Excel для налоговой декларации
- **API** — REST API для возможных мобильных клиентов
- **Мультисемья** — несколько независимых семей на одном инстансе
